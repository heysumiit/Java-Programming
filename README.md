## Compile and Run

Make sure the Java Development Kit (JDK) is installed and available in your system's PATH.

### Check Java Version

```bash
java --version
```

### Compile a Java File

```bash
javac Main.java
```

### Run the Program

```bash
java Main
```

Replace `Main.java` with your Java source file name. The public class name must match the filename.
